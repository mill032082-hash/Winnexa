# Winnexa · Investigación de mercado

Panel local de investigación 360°, con menú lateral oscuro, paneles azul marino, acentos morados y bloque verde, tomando como referencia la captura compartida.

## Secciones

- **Resumen:** avance del dossier, cobertura y siguientes tareas.
- **Ficha del producto:** identidad, país, fuente, proveedor, ventas de catálogo, etiqueta, INCI, uso, alérgenos, claims, costo, precio objetivo y modelo de pago.
- **Voz del cliente:** citas, preguntas, objeciones, likes/votos, idioma y fuente.
- **Competidores:** país, canal, precio y moneda, oferta, forma de pago, anuncios observados y URL.
- **Anuncios:** plataforma, formato, anunciante, fechas observadas, gancho, ángulo, oferta y enlace.
- **Ángulos y huecos:** evidencia, audiencia, promesa permitida y dos conceptos creativos.
- **Informe:** descarga un HTML autocontenido con los hallazgos ingresados y pendientes explícitos.

## Datos iniciales

El dossier parte de **Drenaje linfático Aurelys** y una observación de catálogo Dropi Perú consultada el 18 de octubre de 2026: 193 ventas en 30 días, 56 en 7 días, stock 293 y proveedor Nibresma marcado como verificado por la fuente. Esto no confirma composición, etiqueta, eficacia ni autorización regulatoria. Las demás secciones están vacías hasta documentar evidencia.

## Límites

- Abrir `index.html` en el navegador. Los registros se guardan en el almacenamiento local de ese navegador.
- Este panel no realiza búsquedas web ni se conecta automáticamente a DropKiller, Meta, Dropi, Claude o Vercel.
- El informe solo presenta datos guardados. Los campos vacíos se muestran como pendientes.
- Los recordatorios sobre claims no sustituyen una revisión regulatoria.
- La integración real con la plataforma existente requiere sus archivos de código y backend autenticado. No guardar credenciales de API en JavaScript del navegador.
